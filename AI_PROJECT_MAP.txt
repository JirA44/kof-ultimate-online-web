└──────────────────────────────────────────────────────────────────────────────┘

Ce projet est un jeu de combat style King of Fighters (KOF) basé sur le moteur
MUGEN/Ikemen GO avec un système multijoueur en ligne personnalisé (Battle.net).

EXÉCUTABLE PRINCIPAL: Ikemen_GO.exe (ou Ikemen_GO_x64.exe)
DOSSIER RACINE: D:\KOF Ultimate Online\

COMMANDES WEBSOCKET:
- register: { playerId, username }
- find_match: { playerId, mode: "quick"|"ranked" }
- create_room: { name, password, maxPlayers }
- join_room: { roomId, password }
- leave_queue: { playerId }
- chat: { roomId, message }

ÉVÉNEMENTS SERVEUR:
- registered: Connexion confirmée
- searching: En file d'attente
- match_found: Match trouvé { opponent, elo }
- room_created: Salle créée { roomId }
- game_start: Début du combat

DÉMARRER LE SERVEUR:
cd online_backend && node matchmaking_server.js
