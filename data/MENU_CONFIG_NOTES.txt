=== MENU GRAPHIQUE (original) ===
Position centree: menu.pos = 475,240
Police graphique:
  menu.item.font =           (vide = invisible quand non selectionne)
  menu.item.active.font = 8  (font 8 = Menu Black .fnt)
  menu.item.spacing = 0, 0   (tous les elements empiles)

Caracteres disponibles dans Menu Black .fnt:
  A = ARCADE
  B = VS MODE
  C = TEAM ARCADE
  D = TEAM VS
  E = TEAM CO-OP
  F = SURVIVAL
  G = SURVIVAL CO-OP
  H = TRAINING (affiche "practice")
  I = WATCH
  J = OPTIONS
  K = EXIT
  L = NON DISPONIBLE (pas d'image)

Tous les elements en texte complet:

  menu.itemname.versus = "VS MODE"

===============================================
STRUCTURE DE LA POLICE Menu Black .fnt
===============================================

Format: Elecbyte FNT v256
Createur: Z - CharCAD - www.zcharcad.kit.net
Taille: 427226 octets

Structure interne:
- Header Elecbyte (0-72)
- Donnees PCX (72 - 426910) = image 8192 x 480 pixels
- Section [Def] (426910+)
- Section [Map] (427086+)

Section [Map] - mapping des caracteres:
  A 0 640      (offset X, largeur)
  B 640 640
  C 1280 640
  D 1920 640
  E 2560 640
  F 3200 640
  G 3840 640
  H 4480 640
  I 5120 640
  J 5760 640
  K 6400 640
  (L 7040 640) - peut etre ajoute mais pas d'image

Chaque caractere = 640 pixels de large, 480 pixels de haut
Image PCX = 8192 pixels de large (espace pour ~12 caracteres)

===============================================
PROBLEME NETPLAY/ONLINE
===============================================

La police graphique "Menu Black .fnt" n'a que les caracteres A-K.
Le caractere "L" peut etre ajoute au mapping mais sans image,
IKEMEN l'ignore completement.

SOLUTIONS:
1. Utiliser le menu TEXTE (fonctionne, moins joli)
2. Modifier la police avec Fighter Factory 3:
   - Telecharger: https://fighterfactory.virtualltek.com/
   - Ouvrir Menu Black .fnt
   - Ajouter caractere L avec image "ONLINE"
   - Sauvegarder

Script disponible: tools/add_online_character.py
  - Ajoute L au mapping de la police
  - Ne cree PAS l'image (juste le mapping)
