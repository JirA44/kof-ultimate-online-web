matchmaking_server.js (24KB) ★ FICHIER PRINCIPAL
─────────────────────────────
FONCTION: Serveur WebSocket pour matchmaking temps réel
PORT: 3101

STRUCTURES DE DONNÉES:
- connectedPlayers: Map<playerId, {ws, info}>     // Joueurs connectés
- matchmakingQueue: [{playerId, elo, mode, ts}]   // File d'attente
- activeMatches: Map<matchId, {p1, p2, status}>   // Matchs en cours
- customRooms: Map<roomId, {host, players, cfg}>  // Salles custom

COMMANDES CLIENT → SERVEUR:
┌────────────────────┬─────────────────────────────────────────────────────┐
│ COMMANDE           │ PAYLOAD                                             │
├────────────────────┼─────────────────────────────────────────────────────┤
│ register           │ { playerId, username }                              │
│ find_match         │ { mode: "quick" | "ranked" }                        │
│ leave_queue        │ { }                                                 │
│ create_room        │ { name, password?, maxPlayers?, mode? }             │
│ join_room          │ { roomId, password? }                               │
│ leave_room         │ { roomId }                                          │
│ chat               │ { roomId, message }                                 │
│ game_result        │ { matchId, winner, loser }                          │
│ challenge          │ { targetPlayerId }                                  │
│ accept_challenge   │ { challengeId }                                     │
│ decline_challenge  │ { challengeId }                                     │
└────────────────────┴─────────────────────────────────────────────────────┘

RÉPONSES SERVEUR → CLIENT:
┌────────────────────┬─────────────────────────────────────────────────────┐
│ ÉVÉNEMENT          │ PAYLOAD                                             │
├────────────────────┼─────────────────────────────────────────────────────┤
│ registered         │ { playerId, message }                               │
│ searching          │ { message, queuePosition }                          │
│ match_found        │ { opponent, elo, matchId }                          │
│ left_queue         │ { message }                                         │
│ room_created       │ { roomId, room }                                    │
│ room_joined        │ { room }                                            │
│ player_joined      │ { playerId, room }                                  │
│ game_start         │ { matchId, opponent }                               │
│ elo_update         │ { newElo, change }                                  │
│ challenge_received │ { challengeId, from, elo }                          │
│ player_online      │ { playerId }                                        │
│ player_offline     │ { playerId }                                        │
│ error              │ { message }                                         │
└────────────────────┴─────────────────────────────────────────────────────┘

SYSTÈME ELO:
- ELO par défaut: 1500
- K-factor: 32
- Range matchmaking: ±200 ELO
- Formule: K * (1 - expectedWin)
  où expectedWin = 1 / (1 + 10^((loserElo - winnerElo) / 400))

PORT: 3100 (par défaut)

ENDPOINTS:

Dans le jeu (data/system.def), le menu "MULTIJOUEUR EN LIGNE" (option L)
ouvre un sous-menu avec:

- QUICK MATCH   → Appelle findMatch("quick")
- LOBBIES       → Affiche liste des salles, permet create/join
- RANKED 1v1    → Appelle findMatch("ranked")
- RETOUR        → Retour menu principal

Le client battlenet_client.js gère la communication entre le jeu
et le serveur matchmaking_server.js.
