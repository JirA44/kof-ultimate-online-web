## 🔧 Personnalisation

### Ajout de Personnages
1. Copier le dossier du personnage dans `chars/`
2. Ajouter une ligne dans `data/select.def` section `[Characters]` :
   ```
   nom_personnage/nom_personnage.def
   ```
3. Lancer : `python auto_test_system.py` pour valider

### Ajout de Stages
1. Copier le fichier `.def` du stage dans `stages/`
2. Le stage sera automatiquement disponible

### Changement Fond de Menu
Éditer `data/system.def` section `[TitleBGdef]`

## 🐛 Dépannage Rapide

### Jeu crash au démarrage
```bash
python auto_repair_system.py
```
Résout 90% des problèmes automatiquement.

### Manette non détectée
1. Vérifier que la manette est branchée
2. Lancer : `python gamepad_auto_config.py`
3. Relancer le jeu

### Personnage ne charge pas
Le système désactive automatiquement les personnages défectueux.
Consulter `mugen.log` pour plus de détails.

### Performance lente
- Fermer les applications en arrière-plan
- Réduire la résolution dans `data/mugen.cfg`
- Désactiver certains effets visuels

## 📬 Support & Contribution

### Pour signaler un problème :
1. Consulter la documentation dans `docs/`
2. Lancer `python auto_repair_system.py`
3. Vérifier `mugen.log` pour les erreurs
4. Consulter `FINAL_REPORT.txt` pour l'état du système
5. Ouvrir une issue sur GitHub avec :
   - Description du problème
   - Contenu de `mugen.log`
   - Étapes pour reproduire

1. **Fork** le projet
2. **Créer** une branche : `git checkout -b feature/nouvelle-fonctionnalite`
