**Formule:**
```
Score = 20
  - (Bugs critiques × 3)
  - (Bugs majeurs × 1)
  + (Roster >= 20 ? +2 : -2)
  + (Tests >= 100 ? +1 : 0)
  + (Multijoueur OK ? +3 : 0)
  + (0 crashs ? +2 : 0)
```

**Exemple actuel:**
```
20 - (2×3) - (0×1) + 2 + 1 + 1 + 2
= 20 - 6 + 6
= 20/20
```

## 🆘 DÉPANNAGE

### ❌ "Python n'est pas reconnu"

**Solution:**
```batch
# Vérifier Python installé
python --version

# Si erreur, télécharger:
https://www.python.org/downloads/
# ✓ Cocher "Add Python to PATH"
```

### ❌ "PIL module not found"

**Solution:**
```bash
pip install Pillow
```

### ❌ Le dashboard ne s'actualise pas

**Solution:**
```bash
# 1. Relancer un audit
python ESPORT_QUALITY_MONITOR.py

# 2. Rafraîchir la page (F5)
```

### ❌ Les portraits ne sont pas créés

**Solution:**
```bash
# 1. Vérifier les permissions
# 2. Relancer en admin
# 3. Vérifier le dossier chars/ existe
```
