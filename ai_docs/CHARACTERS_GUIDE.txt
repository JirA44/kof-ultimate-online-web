[Characters]
; Format: chemin/personnage.def, stage, order, music
chars/Kyo/Kyo.def, stages/KOF_Stadium.def, order=1
chars/Iori/Iori.def, random
chars/Athena/Athena.def, stages/Temple.def, order=2, music=chars/Athena/theme.mp3

PARAMÈTRES:
- chemin.def    → Chemin vers le fichier définition du personnage
- stage         → Stage associé (ou "random")
- order=N       → Ordre d'apparition dans l'arcade (1-10)
- music=path    → Musique personnalisée

[ExtraStages]
; Stages additionnels
stages/Beach.def
stages/City.def

[Options]
; Configuration
arcade.maxmatches = 10,0,0,0,0,0,0,0,0,0

├── [name].def           ★ Fichier définition principal

┌──────────────────────────────────────────────────────────────────────────────┐
│                      AJOUTER UN PERSONNAGE                                    │
└──────────────────────────────────────────────────────────────────────────────┘

1. COPIER LE DOSSIER:
   Copier le dossier du personnage dans chars/
   Ex: chars/NouveauPerso/

2. VÉRIFIER LA STRUCTURE:
   - NouveauPerso.def existe
   - NouveauPerso.sff < 100MB
   - Fichiers .air, .cmd, .cns présents

3. AJOUTER DANS SELECT.DEF:
   Éditer data/select_final.def
   Ajouter: chars/NouveauPerso/NouveauPerso.def

4. TESTER:
   python test_chars_stability.py

5. SI ERREUR:
   - Vérifier syntaxe du .def
   - Vérifier que .sff n'est pas corrompu
   - Essayer avec un stage différent

┌──────────────────────────────────────────────────────────────────────────────┐
│                      RETIRER UN PERSONNAGE                                    │
└──────────────────────────────────────────────────────────────────────────────┘

1. Éditer data/select_final.def
2. Commenter ou supprimer la ligne:
   ; chars/PersonnageARetirer/PersonnageARetirer.def
3. Le dossier peut rester dans chars/ (ne sera pas chargé)

ERREUR: "Character not found"
→ Vérifier le chemin dans select.def
→ Vérifier que le fichier .def existe

ERREUR: "Error loading sprites"
→ Fichier .sff corrompu ou trop gros
→ Essayer de réduire la taille

ERREUR: "Animation not found"
→ Fichier .air manquant ou incomplet
→ Vérifier les références dans le .air

CRASH AU CHARGEMENT:
→ Personnage probablement trop lourd (>100MB)
→ Retirer de select.def et tester

JEU LENT:
→ Trop de personnages chargés
→ Utiliser select_tested.def (50 chars max)
