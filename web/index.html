Installation Rapide

  1. Télécharger le paquet Windows

    Un seul fichier de téléchargement pour démarrer : l’installateur KOFUO disponible actuellement.

  2. Installer et lancer

    Ouvrez le fichier téléchargé et suivez les instructions affichées. Le projet cible Windows 10/11 64 bits.

  3. Jouer

    Le launcher regroupe l’accès au jeu et aux fonctions disponibles dans votre installation.

⬇ Télécharger KOFUO pour Windows (EXE, 39,3 Mio)
Options avancées et dépannage

Si l’installateur ne convient pas à votre installation, téléchargez séparément le launcher Windows ou le client multijoueur Python. Le client Python nécessite Python et ses dépendances.

Consulter le guide complet d’installation et d’utilisation.

Limite actuelle : les personnages (environ 9,7 Go selon la documentation du projet) ne sont pas inclus dans le dépôt et aucun lien de téléchargement de ces fichiers n’y est indiqué. Le fichier unique disponible ne peut donc pas être présenté comme une installation complète de tout le roster.

Jeu en ligne : le client multijoueur fourni utilise encore ws://localhost:8765 par défaut. Il faut déployer un serveur de matchmaking public avant que les joueurs puissent se rejoindre sur Internet.
